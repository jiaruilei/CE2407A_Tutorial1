# CE2407A · Tutorial 1

Interactive exercises for Q2, Q3, Q4 and Q7, using the CE2134 teaching-page style.

Open `index.html` in a browser. Keep `styles.css` and `tutorial.js` beside it. No build step, external libraries or network connection is needed.

Run the calculation and interaction checks with Node.js:

```sh
node --test tests/tutorial.test.cjs
```

The default results follow Tutorial Set 1. Q3 uses the exact `P(U) = 0.10018`; Q4 recognises the equal contributions of A and C (`0.072` each). Hints are local, rule-based responses.
